# Lenco DIR-70BK Remote

Native Android remote for AirMusic-compatible Lenco DIR-70BK radios.

Features:
- automatic LAN discovery with manual IP fallback
- now-playing / stream information
- remote-control keys and navigation
- volume, mute and playback controls
- Internet Radio station search
- favourites
- Bluetooth pairing/status
- remembers the last working radio IP

The app communicates only with the radio on the local Wi-Fi network using the radio's AirMusic HTTP interface.
