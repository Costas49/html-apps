Επικόλλησε το Gemini API key και όρισε ένα PIN. Το κλειδί θα αποθηκευτεί κρυπτογραφημένο σε αυτή τη συσκευή.

Έξι ή περισσότερα ψηφία προσφέρουν καλύτερη προστασία.
Το PIN δεν αποστέλλεται στην Google. Αν το ξεχάσεις, θα χρειαστεί να διαγράψεις την τοπική ρύθμιση και να αποθηκεύσεις ξανά το κλειδί.
