# Kostas Brilliance AI

Ελαφριά εφαρμογή Android για σύνοψη, ιεραρχικό δέντρο ιδεών, αναλυτική εξήγηση, μετάφραση και συζήτηση με δωρεάν κλειδί Gemini API.

- Android 6.0+ (βελτιστοποιημένη για Android 10)
- Το κλειδί API αποθηκεύεται κρυπτογραφημένο στο Android Keystore.
- Νέο application id: `gr.kostas.brillianceai`, ώστε να μην συγκρούεται με παλιές εφαρμογές Kostas AI.
- Κοινά αρχεία έως 12 MB συνολικά ανά αίτημα.

Η δωρεάν βαθμίδα Gemini έχει όρια χρήσης. Η εφαρμογή δεν παρακάμπτει, δεν χρεώνει και δεν κρύβει αυτά τα όρια.
